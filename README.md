# PR-календарь и медиапотенциал заявок Фонда президентских грантов

Python-пайплайн для анализа заявок на президентские гранты через LLM API. Формирует PR-календарь внешних инфоповодов и стратегический PR-бриф со скрытым медиапотенциалом.

## API

Используется **Anthropic Claude API** (модель `claude-sonnet-4-20250514`). Ключ задаётся через переменную окружения `ANTHROPIC_API_KEY`.

## Запуск

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
python main.py --input data/sample_applications.json --output output
```

Результаты появятся в папке `output/`: файл `results.json` и `results.xlsx`.

## Промпты

Для каждой заявки формируются два промпта:
1. **PR-календарь** — извлечение внешних инфоповодов из календарного плана. Промпт содержит явные правила отбора (что включать / что исключать) и требует структурированный JSON с полями `date`, `title`, `event_type`, `pr_score`, `why_it_matters`, `how_to_strengthen`, `pr_format`.
2. **Стратегический PR-бриф** — поиск скрытого медиапотенциала (человеческие истории, сезонные привязки, визуальные форматы, партнёрства). Возвращает JSON с полями `title`, `category`, `media_potential`, `timing`, `effort_level`, `media_formats`, `recommendation`.

## Извлечение и валидация JSON

Парсер LLM-ответов обрабатывает: прямой JSON, markdown-обёртку ` ```json `, текст вокруг JSON, trailing commas. Каждая запись валидируется через Pydantic-модели (типы, обязательные поля, допустимые значения). Невалидные записи сохраняются в `validation_errors`.

## Quality Layer

После валидации каждая запись проходит quality-check:
- **PR-календарь**: фильтр по `pr_score` (порог 5), проверка на маркеры внутренней деятельности, детектор расплывчатых формулировок, проверка формата даты.
- **PR-бриф**: проверка конкретности формулировок, валидность `effort_level`, достаточная длина рекомендаций.

Каждой записи присваивается `quality_status` (`accepted` / `review` / `rejected`) и `quality_comment`. Отклонённые записи сохраняются в выходных данных, но визуально выделены в Excel. Пакетная обработка продолжается при ошибке отдельных заявок.
